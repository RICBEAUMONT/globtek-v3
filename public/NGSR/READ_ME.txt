UPLOAD
1. Create a folder such as ngsr-signature inside your website's public folder.
2. Upload every file and the entire assets folder from this package into it.
   Keep the directory structure and filenames unchanged. index.html should sit
   directly inside ngsr-signature, alongside brand.html, app.js and the CSS files.
3. Open https://YOUR-DOMAIN/ngsr-signature/index.html
   The brand guide is at https://YOUR-DOMAIN/ngsr-signature/brand.html

No build command, installation, database, API key or server code is required.
Use normal static file hosting. A WordPress page editor will not execute this
package: upload the files using your host's file manager or SFTP instead.

DIRECT IMAGE URLS — AUTOMATIC
When opened from your hosted website, the copied signature and downloaded HTML
automatically reference the images on that domain, including when the tool is
installed in a subfolder. No manual image URL configuration is required.

For the example folder above, the direct image paths are:
https://YOUR-DOMAIN/ngsr-signature/assets/ngsr-logo.png
https://YOUR-DOMAIN/ngsr-signature/assets/ngsr-banner-midnight.jpg
https://YOUR-DOMAIN/ngsr-signature/assets/ngsr-banner-bronze.jpg
https://YOUR-DOMAIN/ngsr-signature/assets/ngsr-banner-homeward.jpg

These are examples, not live links. Use your actual domain and installation path.
The image files must open directly without login, expiry or a file-sharing page.
Serve PNG as image/png, JPG as image/jpeg, WOFF as font/woff, OTF as font/otf,
JS as application/javascript and CSS as text/css. Permit image requests without
session cookies or a referrer. Keep this asset folder online after staff copy
their signatures: recipient emails will request these URLs.

CHECK BEFORE ROLLOUT
- Use HTTPS; the formatted clipboard function depends on browser support and
  permissions. Select signature is provided for manual copying if needed.
- Open the logo and all three banner URLs in a private/incognito window.
- Change the personal details, choose each banner, and check the preview.
- Copy into Outlook's signature settings, save, and send a test email.
- Verify the telephone, email and website links and check on a second device.
- If Outlook removes an image, use the supplied downloads and Insert Picture.

SIGNATURE SIZES
Name: 14 pt. Title / phone / email / website: 10 pt.
Optional professional designations: 9 pt. Disclaimer: 8 pt.
Logo: 175 x 41 px. Banner: 480 x 152 px.
The extra spacing beneath the logo is included. Labels are T: and E:.
All banners are static. No animation is included.

FONTS
Canva Sans is loaded on the website. Downloadable desktop font files are available
in the Brand Guide. Email text requests Canva Sans with Arial as fallback;
recipients' email software may use the fallback. Web fonts are not embedded
into recipients' email clients.

PRIVACY AND LOCAL PREVIEW
Staff details are processed in the browser; the generator has no form server,
tracking, analytics or database. The website contains reference details as
editable defaults, which staff should replace with their own.
Opening index.html directly from disk can preview the site; image embedding is
used as a fallback in that case. Test copying from the actual HTTPS website.

CUSTOMISATION
Edit the supplied HTML, CSS and JavaScript files to change the generator.
Replacing images under existing filenames can affect existing signatures after
email clients refresh their cached image. Use new filenames when you want to
keep older signatures unchanged.
